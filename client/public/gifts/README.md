# مجلد أنيميشن الهدايا (فيديو MP4 / WebM)

> **الاستضافة الحالية = GitHub Releases (CDN)**، وليست هذا المجلد.
> الفيديوهات مرفوعة على إصدار `gift-assets-v1`، وحقل `asset` لكل هدية في
> `server/gifts.json` يشير إلى رابط مطلق مثل:
> `https://github.com/zaiem1418-png/game/releases/download/gift-assets-v1/lion.mp4`
> لذلك ملفات `*.mp4` هنا **متجاهَلة في Git** (انظر `.gitignore`) ولا تُرفع مع المستودع.
>
> **لإضافة/استبدال فيديو**: ارفعه كأصل على الإصدار (أو استخدم زر الرفع في لوحة الإدارة)،
> ثم ضع رابطه في حقل `asset`. لتحديث نفس الاسم، احذف الأصل القديم من الإصدار أولاً.

ما تحت هذا السطر يشرح الطريقة المحلية البديلة (وضع الملفات هنا مباشرة):
المحرك يلتقط أي ملف بالاسم الصحيح تلقائياً، وإن لم يوجد يتراجع إلى السيناريو المُولّد + مؤثّر صوتي.

## المواصفات الموصى بها
- الصيغة: **MP4 (H.264)** أو WebM. يفضّل خلفية سوداء أو شفافة (WebM/VP9 alpha).
- الأبعاد: 720×1280 (عمودي) أو 1080×1080. المدة تطابق `duration` الهدية (٦–٨ ثوانٍ للكبيرة).
- **الصوت الواقعي يُدمج داخل ملف الـMP4 نفسه** (زئير/محرك/دوّار) — يُشغَّل مع الفيديو تلقائياً.
  إن أردت صوتاً منفصلاً بدل ذلك، ضع ملفات الصوت في مجلد `../sounds/`.
- حجم كل ملف: أبقه تحت ~3MB لسرعة التحميل على الجوال.
