# مجلد الأصوات الواقعية (MP3 / WAV / OGG)

ضع هنا ملفات الصوت الحقيقية. المحرك يشغّلها في اللحظة الصحيحة داخل الأنيميشن
(زئير الأسد عند الهبوط، محرك فيراري عند الاندفاع، دوّار الهليكوبتر...). وإن لم يوجد
الملف يتراجع تلقائياً إلى المؤثّر المُولّد برمجياً (synth) — فلا شيء يتعطّل.

> ملاحظة: هدايا الفيديو (MP4) عادةً تحمل صوتها مدمجاً داخلها، فلا تحتاج ملفاً منفصلاً
> إلا إن أردت صوتاً خاصاً بحدث معيّن، أو كانت الهدية تعتمد الرسم المُولّد (بلا MP4).

## المواصفات
- الصيغة: **MP3** (الأفضل توافقاً) أو WAV/OGG. أحادي أو ستيريو.
- المدة: قصيرة ومركّزة (١–٣ ثوانٍ) لتتزامن مع لحظة الحدث.
- المستوى: طبيعي (تجنّب التشويه/الـclipping)؛ المحرك يتحكم بالحجم.
